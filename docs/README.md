# MS Monitoring Docs

This directory is intentionally split across two publication targets:

- `README.md`: landing page shown when browsing `docs/` on GitHub
- `index.md`: landing page for GitHub Pages when the site is published from `/docs`
- `index.rst`: Sphinx entry point used to build the full Read the Docs site

## Active publishing model

This repository uses the following setup:

- GitHub folder view: `docs/README.md`
- GitHub Pages: Jekyll from `docs/` using `docs/_config.yml`
- Read the Docs: Sphinx from `docs/index.rst` using `docs/conf.py`

## Important note

Do not add a `.nojekyll` file to `docs/` when publishing GitHub Pages from
`/docs`, because that would disable the Jekyll theme.

The `.nojekyll` file generated by Sphinx belongs only in built output such as
`docs/_build/html/`.

## Documentation entry points

- GitHub folder view: [README.md](./README.md)
- GitHub Pages source: [index.md](./index.md)
- Sphinx source: [index.rst](./index.rst)
- Jekyll config: [_config.yml](./_config.yml)
- Read the Docs build config: [../.readthedocs.yaml](../.readthedocs.yaml)

## Local Sphinx build

```bash
pip install -r docs/requirements.txt
cd docs
make html
```

The generated HTML site will be available at `_build/html/index.html`.
